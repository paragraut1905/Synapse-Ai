🤖 Synapse AI – Integrated AI Platform

Synapse AI is a full-stack AI platform built using the MERN STACK + Clerk Authentication. It provides a suite of AI tools that help users generate articles, create blog titles, generate AI images, remove object, remove background, review resume — all powered through API integrations.

🚀 Features (Core + Key Functionalities)

📝 AI Article Generation – Generate long, high-quality articles instantly. ✍️ AI Blog Title Generator – Produce engaging and SEO-friendly blog titles. 🎨 AI Image Generator – Create images from text prompts. ✂️ Remove Background – Remove backgrounds from uploaded images. 🧽 Remove Objects from Image – Erase unwanted objects using AI inpainting. 🔐 Clerk Authentication – Secure login/signup with user dashboard. ⚙️ API-Driven Tools – All features powered using external AI APIs. 📱 Responsive UI – Clean, intuitive, and mobile-friendly layout.
